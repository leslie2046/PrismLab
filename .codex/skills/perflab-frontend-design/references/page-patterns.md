# Page patterns

## Workspace shell

Persistent compact sidebar groups work and configuration. Main header gives location without repeating page descriptions. Mobile uses an explicit drawer. Keep navigation and account actions keyboard accessible.

## Object indexes

Heading plus create action, then search/filter toolbar and list/table. Row names open details. Status, purpose and timestamps support scanning. Empty states explain the next useful action. Keep pagination and selection independent of decorative layout.

## Dataset detail

Object heading with back navigation. Local navigation separates **样本 / 评测记录 / 设置**. Samples has search, import/add, export, review and selection controls. Question/answer rows show relevant context counts, status and compact row actions. A secondary overview panel can show genuine totals and source information; collapse below main content on narrow screens.

Evaluation history belongs to the dataset. New evaluations use the current dataset, respect its purpose, and retain independent frozen versions, metric results and comparisons. Filter records on the server by their immutable dataset version before applying list limits. Keep old links readable without offering a competing creation flow.

Settings contains inline basic metadata and generation configuration with clear save actions, followed by source management. Import documents, sync knowledge base and rebuild remain explicit dialogs with prerequisites and consequences. Save does not implicitly build. Preserve existing saved defaults and user overrides.

## Configuration

Group by task, with section labels and moderate form widths. Avoid long uninterrupted forms or grids of unrelated launch buttons. Keep advanced fields collapsed where possible. Show explanation with InfoTip rather than permanent paragraphs. Report success near the save action, and preserve failed-save drafts.

## Evaluations and analysis

Show actual metric scores, completion state and sample results before technical configuration. Use tabs for separate result views. Comparisons explain baseline, candidate and direction of change. Preserve backend semantics, provenance and missing-score states.

## Dialogs and responsive behavior

Dialogs have a concise title, scrollable body and visible footer. Maintain Escape, focus behavior, native labels and accessible close controls. Small screens use full available width and wrap actions. Never hide essential actions simply to avoid overflow. Wide analysis tables may scroll horizontally; sample prose should wrap.
