# 列表多选与批量操作

数据集详情的数据项、测试计划、运行记录支持复选框多选。勾选表头复选框选择当前页，再次取消勾选可清除当前页选择；不再显示独立的「全选当前页」「选择全部筛选结果」「全不选」按钮。选中记录后显示已选择数量及适用的批量操作，未选择且没有操作反馈时隐藏批量工具栏。每次最多选择 20000 条，更多记录需缩小筛选范围。

翻页、调整每页条数和自动刷新保留勾选；切换筛选条件、列表或空间时清空。部分勾选时表头显示半选状态。勾选复选框不会打开详情或编辑器，支持键盘操作。

| 列表 | 批量操作 | 状态与权限 |
| --- | --- | --- |
| 数据项 | 导出、启用、归档、删除 | 生成期间禁止修改，允许导出；团队成员可维护与导出数据项 |
| 测试计划 | 开始、暂停、停止、删除 | 自动跳过不适用的状态；删除需要所有者或管理员权限 |
| 运行记录 | 取消运行、删除 | 仅取消排队/运行中的任务，仅删除已结束记录及其报告；删除需要所有者或管理员权限 |

批量开始、停止、取消和删除会先说明影响并确认。停止或删除计划会取消当前运行，保留历史运行记录；开始计划可能立即触发测试及模型调用。

操作结果显示成功、跳过及失败的数量。成功记录取消勾选，跳过和失败记录保留勾选，可继续选择适用操作或重试。计划及运行记录逐条返回结果，部分失败不隐藏已完成操作；前端每批提交 100 条，切换空间后不再提交剩余批次。单次计划/运行 API 最多 500 个 ID。数据项整批修改在同一事务中完成，缺失或属于其他数据集的 ID 会拒绝整批，避免部分删除。批量启用/归档视为人工维护，变更记录会受重新构建的人工数据保留规则保护。

沿用登录、CSRF 和空间隔离，无数据库迁移。选择快照接口为 `GET /api/plans/selection`、`GET /api/runs/selection` 和 `GET /api/datasets/{id}/items/selection`；查询条件与对应列表一致。批量接口为这些资源的 `POST .../bulk`，请求体为 `{ "action": "...", "ids": [...] }`，响应包含 `succeeded`、`skipped` 和 `failed`。

数据项导出在「批量导出」弹窗中选择文件格式（JSON、JSONL、CSV）与导出范围。默认导出已勾选记录，无勾选则默认整个数据集；跨页选择有效，下载后保留勾选。导出整库使用原有 `GET /api/datasets/{id}/export`，指定勾选使用 `POST /api/datasets/{id}/export?format=...` 及 `{ "ids": [...] }`，按数据集顺序生成一个文件；记录缺失时拒绝整批导出，错误保留在弹窗内，可调整格式后重试。
