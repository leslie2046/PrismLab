# LLM 模型定义与请求参数

模型能力与供应商字段映射由 [模型定义 YAML](../config/llm-models.yaml) 提供，部署端点、凭据与空间默认值保存在 PostgreSQL。

## 当前使用方式

- LLM 供应商共用基础参数（`max_tokens`、`temperature`、`top_p`）。未知模型不会按名字猜测思考能力，界面明确显示基础兼容配置。
- Playground 选择模型后动态生成表单，思考模式与 effort/budget 联动；未设置的可选参数不发送，使用服务默认。Playground 的 max_tokens 默认留空，不发送该字段；测试计划与 LLM CLI 默认 256。显式设置时应用侧上限为 8192，服务较小的上限会进一步约束它。
- DeepSeek、硅基流动、vLLM、阿里云和 Xinference 的已明确列出的混合思考模型有对应 YAML 参数映射。思考参数不是所有模型或所有部署都支持，实际 UID 必须与 YAML 中 provider + patterns 精确匹配。
- 「刷新模型能力」对已接入模型列表接口的 DeepSeek、硅基流动、vLLM、Xinference、百炼和华为云 MaaS 开放，只请求模型列表，不生成文本、不自动保存模型配置；缓存有效期 1 小时，按供应商、端点、模型 UID 和凭据隔离。服务未返回字段时保持未知，失败不覆盖已有表单。
- DeepSeek 官方返回的 effort 档位可以覆盖 YAML 档位；其他供应商未声明字段映射时不自动开启此能力。服务容量元数据可补充 YAML，系统安全上限不被放宽。
- 流式思考内容默认展开，答案独立显示；TTFT 仍是首个任意输出，TPOT/tokens/s 仍按服务报告的总输出 token 计算，界面明确注明口径。原始结果包含本次显式参数与能力定义版本，但 Playground 不创建持久运行记录。
- Playground LLM 请求总时限默认 300 秒，界面可调整到 600 秒，包含思考与答案输出；其他测试类型仍默认 30 秒。超时会保留已收到的内容并明确标明原因，只有思考内容时提示未收到最终答案，不记为回答成功。`max_tokens` 耗尽也会单独提示，思考与答案可能共享输出预算。数据集与性能测试的超时设置不受此默认值调整影响。

新增本地部署 UID 时，在 `models` 中加入一条明确规则，例如：

```yaml
  - provider: vllm
    patterns: [my-qwen-deployment]
    profile: qwen_template
    metadata:
      context_window: 32768
      max_output_tokens: 8192
```

只有确认部署聊天模板支持 enable_thinking 时才能使用该 profile。其他模型可以新增 profile，配置参数类型、范围、提示语、依赖和允许的 api_field；认证、messages、model、stream 等受控字段不能被 YAML 或请求覆盖。修改 YAML 后新请求会重新读取，无需改 React 代码。

## 各入口的思考设置

- **Playground**：按模型能力显示思考模式、强度与预算。调试样本生成步骤时自动带入已记录且适用的参数。
- **数据集生成与质量评测**：在「空间设置」中分别保存生成、质量评审、结果评分的思考模式。实际发送字段由模型能力决定。生成追溯和评测证据保存相应请求参数。
- **AI 测试报告**：在「空间设置 → AI 测试报告」配置模型和思考模式，再从已结束的运行记录手动生成。分析输入包含性能统计、模型标识、输入长度和文档数量。报告保存在 PostgreSQL，只有重新分析成功才替换上一次报告；删除运行时会一并删除。
- **性能测试和 CLI**：通过各入口支持的参数配置请求。CLI 参数和性能指标口径见 [CLI 参考](cli-reference.md)；用量缺失时，依赖供应商 token 计数的速度指标不可用。

YAML 可以扩展模型匹配规则、参数范围、依赖条件和受支持的供应商字段。密码、端点和请求消息由连接配置与调用方管理。模型容量元数据与实际推理参数分别使用。
