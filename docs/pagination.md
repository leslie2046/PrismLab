# 列表分页与批量操作

共用分页栏提供首页、上一页、页码选择、下一页和末页按钮，可一键跳转到首尾页。首页或末页对应的按钮在到达边界时禁用；空列表、单页列表和加载中的列表同样遵守禁用状态。

测试计划、运行记录、供应商、供应商内模型及 Dify 配置列表通常每页 10 条，可切换 20 / 50 条，支持前后翻页和页码选择。供应商搜索或类型筛选后回到第一页，模型配置操作仍对应原始模型。删除末页记录后自动回到有效页。列表的计数为当前空间或当前筛选条件的总数，不是当前页条数。

测试计划支持按名称或 ID 搜索，并按状态、测试类型、重复规则筛选。列表显示计划创建时间和下次运行时间；新增或编辑从列表打开弹窗，保存计划后可单独启动。正在运行的计划须先暂停并等待当前运行结束才能编辑。

「运行记录」首页按测试计划分组，可搜索计划并筛选状态与测试类型。打开计划默认显示最新运行结果，「全部运行记录」显示该计划的分页历史。运行时间取实际开始时间 `started_at`，缺字段时显示「—」。Dify 配置可按名称、地址、ID 或类型筛选。

## 分析看板分页

分析看板的“指标数值明细”对当前已加载、筛选后的场景行进行客户端分页，默认每页 10 条，可选 20 / 50 条，支持前后翻页和页码跳转。历史趋势、稳定性和单次运行对比均适用。切换计划、视图、并发档位、指标或对比运行时回到第一页；分页不截断图表数据，不改变曲线和汇总统计。进入分析看板时会通过运行记录分页接口加载当前空间的完整历史，每批 100 条，再按测试计划筛选；不复用首页仅含最近 30 条的运行列表。趋势图、汇总与明细使用同一份完整数据，明细翻页不额外获取历史运行。点击看板顶部“刷新”重新读取完整历史；加载失败会提供重试，初次加载失败不会显示部分数据，刷新失败保留上一份完整结果并显示错误。

## 分页 API

- `GET /api/plans?page=1&page_size=10`
- `GET /api/runs?page=1&page_size=10`
- `GET /api/run-plan-groups?page=1&page_size=10&compact=1`

三个接口均接受 `q`（最长 200 字符，忽略大小写的字面包含匹配）、`status`、`benchmark`；计划接口还接受 `repeat_mode=once|count|forever`，运行接口可用 `plan_id` 限定计划。条件可组合使用，计数和分页均基于筛选后的完整结果。搜索不会将 `%` 或 `_` 解释为通配符。不带 `page` 时也可筛选，仍返回受 `limit` 限制的数组。

提供 `page` 时，返回 `{ "items": [], "total": 0, "page": 1, "page_size": 10 }`。页码从 1 开始，`page_size` 为 1–100。超出末页的页码自动收敛到末页；空列表返回第一页。计划与单条运行按创建时间降序，ID 降序作为并列排序。总数与当前页在同一数据库快照中读取，遵守当前空间的数据隔离和鉴权。

不提供 `page` 时保持原数组响应及 `limit` 行为，兼容现有调用方（计划默认 100，运行默认 30）。配置列表仍由客户端对已加载的完整配置分页，不截断供测试计划和 Playground 选择的模型。

## 批量操作

数据集列表、样本、评测记录、测试计划、运行记录和 Dify 配置提供多选。多数列表用表头复选框选择当前页，Dify 配置可选择筛选后的配置。选中记录后工具栏显示数量和当前可用的操作。样本管理支持「全选全部匹配记录」，按搜索、质量和参考片段数筛选匹配整个数据集。

翻页、调整每页条数和自动刷新保留勾选；切换筛选条件、列表或空间时清空。勾选复选框不会打开详情或编辑器，支持键盘操作。

| 列表 | 批量操作 | 状态与权限 |
| --- | --- | --- |
| 数据集 | 删除 | 团队成员可维护数据集；构建中的数据集跳过 |
| 评测记录 | 删除 | 所有者或管理员；活动评测需先取消 |
| Dify 配置 | 删除 | 所有者或管理员 |
| 数据项 | 导出、启用、归档、删除 | 生成期间禁止修改，允许导出；团队成员可维护与导出数据项 |
| 测试计划 | 开始、暂停、停止、删除 | 自动跳过不适用的状态；删除需要所有者或管理员权限 |
| 运行记录 | 取消运行、删除 | 仅取消排队或运行中的任务；删除需要所有者或管理员权限，按计划批量删除只删除已结束的运行及报告 |

批量开始、停止、取消和删除会先说明影响并确认。停止或删除计划会取消当前运行，保留历史运行记录；开始计划可能立即触发测试及模型调用。

操作结果显示成功、跳过及失败的数量。成功记录取消勾选，跳过和失败记录保留勾选，可继续选择适用操作或重试。计划及运行记录逐条返回结果，部分失败不隐藏已完成操作；前端每批提交 100 条，切换空间后不再提交剩余批次。单次计划/运行 API 最多 500 个 ID。数据项整批修改在同一事务中完成，缺失或属于其他数据集的 ID 会拒绝整批，避免部分删除。批量启用/归档视为人工维护，变更记录会受重新构建的人工数据保留规则保护。

沿用登录、CSRF 和空间隔离。选择快照接口为 `GET /api/plans/selection`、`GET /api/runs/selection` 和 `GET /api/datasets/{id}/items/selection`；查询条件与对应列表一致。批量接口为这些资源的 `POST .../bulk`，请求体为 `{ "action": "...", "ids": [...] }`，响应包含 `succeeded`、`skipped` 和 `failed`。

数据项导出在「批量导出」弹窗中选择文件格式（JSON、JSONL、CSV）与导出范围。默认导出已勾选记录，无勾选则默认整个数据集；跨页选择有效，下载后保留勾选。导出整库使用原有 `GET /api/datasets/{id}/export`，指定勾选使用 `POST /api/datasets/{id}/export?format=...` 及 `{ "ids": [...] }`，按数据集顺序生成一个文件；记录缺失时拒绝整批导出，错误保留在弹窗内，可调整格式后重试。
