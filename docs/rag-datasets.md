# 评测数据集与生成后端

在侧栏「评测数据集」构建和维护单轮 RAG 评测样本。构建时可选择 **DeepEval** 或 **RAGAS** 后端，二者都使用当前空间配置的模型和凭据，并将结果保存为 PrismLab 的 Golden 记录。评测执行、打分和结果对比在「质量评测」中进行，详见 [质量评测说明](quality-evaluations.md)。

数据集用途可设置为 RAG 评测、检索评测或两者通用，列表可按用途筛选；用途不自动补齐答案或人工检索标注。现有数据集默认视为两者通用。数据集支持混合数据来源，列表的「数据来源」列展示各个知识库、文档或导入文件。创建后可以继续导入文档、追加数据、同步 Dify 知识库及手工添加；详情中的「来源资料」列出用于生成的文档与知识库资料。

## 构建入口

Dify 连接可先在「Dify 配置」中填写 Base URL 和 Dataset API Key，获取知识库列表后勾选添加；也支持手动添加。详见 [Dify 知识库配置](dify-configuration.md)。

- **数据集导入**：直接导入 CSV、JSON、JSONL，不调用模型；也可勾选「使用 AI 扩写已有数据集」，选择当前空间的种子数据集，调用 `a_generate_goldens_from_goldens`。仅使用启用的数据项；有参考上下文的种子和无参考上下文的种子需要分开。SDK 提取种子的问题风格，再结合空间提示词和任务要求生成。
- **从文档生成**：上传 TXT、Markdown、文本 PDF、DOCX、CSV，提取文本后调用 `a_generate_goldens_from_contexts`，生成问题、参考答案和参考上下文。扫描 PDF 需先 OCR。
- **从Dify知识库生成**：支持搜索并多选知识库，读取各配置中的知识库 ID 和 Dataset API Key，分页拉取已启用、未归档文档的可用分段，调用相同的 SDK 上下文生成流程。不会修改 Dify 内容。
- **空白数据集**：手动创建和编辑 Golden；也可勾选「使用 AI 按任务生成」，填写生成任务，调用 `a_generate_goldens_from_scratch`。无上下文生成仅产生问题，不编造参考答案。

空间设置中的「模型并发上限」统一控制 DeepEval 与 RAGAS 的并发请求数，范围 1–10，默认 3；新建、追加、重新构建和失败重试均使用当前空间值，数据集表单不再提供覆盖。已运行任务继续使用启动时的快照。

目标大小为 1–500 条。生成模型和可选的质量评审模型均使用当前空间已经配置的端点与加密凭据；空间设置提供「数据集生成模型」「数据集生成质量评审模型」及提示词。生成任务默认继承空间质量评审模型，未配置时复用生成模型；高级配置可单次覆盖评审模型，或显式选择「与生成模型相同」。点击「恢复默认提示词」后保存可重置。提示词通过 SDK 的 `StylingConfig.task` 提供任务要求，输出结构由 SDK 控制；生成记录保存参数、模型和提示词快照。

空间设置另提供「数据集生成质量评审提示词」，用于补充初始问题的清晰度、独立完整性和可回答性等评审标准。它仅传入有参考上下文流程中的 `InputFeedback` 质量评审调用，不影响生成、问题改写或风格提取，评分范围与 JSON 输出结构仍由 SDK 控制；不用于验证参考答案的事实正确性。新建、追加生成和重新构建保存当前空间评审提示词快照，失败重试沿用原快照。历史任务缺少快照时使用内置默认值。点击「恢复默认质量评审提示词」并保存可重置。

「空间设置 → 数据集生成」还可配置默认嵌入模型，供官方 RAGAS 构建使用。构建时未单独选择嵌入模型则继承此配置，单独选择时优先使用本次选择；保存配置不会调用模型。每次构建保存实际使用的模型快照，失败重试沿用该模型，不受之后空间默认值变化的影响。

新建表单依次填写数据集名称、数据集用途，再选择创建方式；知识库选择器按名称展示和搜索，不显示知识库 ID。「生成参考答案」与「答案风格」位于 DeepEval / RAGAS 高级配置下方，两种后端共用。关闭生成参考答案会隐藏答案风格，重新开启时保留已填写内容；无上下文的按任务生成不提供参考答案设置。

## 创建后的维护

点击 Logo 会刷新并返回首页；顶部「评测数据集」和侧栏同名入口可返回列表。详情顶部面包屑显示当前数据集名称，标题区展示状态、用途、片段数及重新构建操作。

打开任意数据集后可以继续：

- **生成配置**：为当前数据集保存生成模型、质量评审模型、每次新增数量、生成方式、参数和专用提示词。保存不调用模型；留空的模型和提示词使用空间默认值。新构建使用新配置，失败续建沿用原任务快照。
- **导入文档**：保存 TXT、Markdown、文本 PDF、DOCX 或 CSV 资料；同名同内容文档去重。每批最多 20 个文件 / 10 MB，累计资料文本最多 200 万字符。导入不会立即生成问答。
- **导入知识库来源**：在样本页标题旁或设置的来源资料中进入，支持一次导入多个知识库。新知识库追加到已有来源中；重新选择已导入的知识库时，只更新这些知识库的快照，保留其他知识库、文档、种子和已有样本。所有来源拉取成功后统一保存，失败保留原资料；期间资料发生其他更新时返回冲突。导入不会调用模型，随后可手动点击「重新构建」追加生成或重建。
- **同步知识库**：在设置的来源资料中，点击具体知识库名称旁的「同步」，更新该知识库的片段快照。其他来源和已有样本保留；同步不调用生成模型，失败时可重试。
- **追加导入 / 添加数据项**：导入已有 CSV/JSON/JSONL 或直接填写问题、答案和上下文。均不调用模型；不同手工上下文片段以空行分隔。
- **追加生成**：按配置的 1–500 条新增数量构建，保留所有已有记录，失败时保留部分结果并支持续建。
- **重新构建**：整批新数据成功后，在同一数据库事务中替换可确认的 AI 生成记录。手工添加、导入、人工编辑及来源无法确认的旧数据保留。失败或服务中断时保留原数据；重试重新生成整批，不提交暂存的部分结果。

文档和 Dify 片段可共同作为上下文；也可选择扩写当前数据集的启用记录，或按任务无资料生成。构建期间锁定配置、资料及数据项修改。应用在 Golden 结构之外记录 `origin`；导出严格排除该字段，手工编辑过的生成记录会转为人工来源，避免重建覆盖修改。历史记录缺少应用保存的 `origin` 时作为来源不明数据保留，不能仅凭可能随导入带入的 SDK 生成元数据判定为可替换记录。无需新增数据库表。

## 生成后端

- **DeepEval**：使用 DeepEval Synthesizer，支持质量评审、问题演化和 Golden 扩写。
- **RAGAS**：使用 RAGAS 单轮样本约定生成 `user_input`、`reference`、`reference_contexts`，然后映射为本地 `input`、`expected_output`、`context`。当前是单轮样本格式兼容适配器，尚未接入官方 `TestsetGenerator`，通过当前空间的模型端点发起请求。

后端选择保存在数据集的生成配置和构建快照中；追加、重新构建及失败重试沿用快照，不会中途切换后端。历史数据集没有后端字段时继续使用 DeepEval。

构建遇到余额或额度不足（HTTP 402）、认证失败（401）、权限不足（403）或模型/地址不存在（404）等明确的请求错误时，会显示具体原因并立即停止重复请求。恢复额度或修正模型配置后可重试；已生成数据保留，替换式重新构建失败时保留原有数据。超时、限流和服务端临时错误仍按原有次数上限重试。

生成表单按后端显示实际支持的参数：DeepEval 提供质量评审模型、质量阈值、评审次数、演化轮数和演化权重；RAGAS 隐藏这些参数，也不解析或调用评审模型。模型并发上限由空间设置统一控制，两个后端共用。RAGAS 的文档/Dify 生成保留上下文片段数；生成任务、应用场景、问题风格和参考答案开关按用途显示。两种后端都使用空间或数据集专用构建提示词。RAGAS 种子扩写会传入种子问题与参考上下文，无上下文时不生成参考答案。

生成任务、应用场景、问题风格和答案风格均使用自然语言填写。每项提供 3 个可点击示例和占位示例，点击只替换当前字段，之后可继续编辑；不会自动保存或开始构建。按任务生成提供不依赖资料的任务示例。新建与已有数据集生成配置共用该交互，并支持中英文。

## DeepEval 配置

空间设置、新建数据集和生成配置中的参数说明统一放在字段名旁的信息图标中，悬停、键盘聚焦或点击可查看。「DeepEval 高级配置」提供用途、取值范围、默认值和调用开销说明；质量阈值、评审次数、演化轮数、模型并发及上下文片段数使用滑动条，旁边实时显示当前数值，支持拖动和键盘调整，沿用原取值范围与步长。演化权重附有例子，按比例抽样而非指定生成条数。错误提示和重新构建的数据保留规则直接显示。支持：

- `FiltrationConfig`：质量阈值、质量评审次数上限、评审模型。
- `EvolutionConfig`：0–3 轮演化，七种演化方式的相对权重（0 禁用）。默认使用具体化、约束、比较，尽量保持资料依据；推理、假设、拓宽主题可能超出来源。多上下文演化需要多个片段；SDK 在无资料生成时忽略该演化方式。
- `StylingConfig`：生成任务、应用场景、问题风格、答案风格。种子扩写还会使用 SDK 的风格提取模板。
- 是否生成参考答案、每组上下文片段数量（1–5）、模型并发上限（1–10）。质量评审只适用于有上下文的生成流程。

演化方式以紧凑列表配置，可勾选启用、填写相对权重，并查看自动计算的抽样占比。每轮抽样一种方式，可连续选中同一种；权重 2 和 1 分别约为 66.7% 和 33.3%，所有方式同为 100 与同为 1 的分布相同。占比不承诺最终样本条数。演化轮数为 0 时暂停改写并保留权重；按任务无资料生成时，多上下文显示为不适用，其他方式的占比按剩余权重计算。恢复默认使用具体化、增加约束和比较，权重各为 1。

SDK 达到评审次数上限后可能保留低分项。`additional_metadata.synthetic_input_quality`、`evolutions` 等 SDK 元数据原样保存，`additional_metadata.prismlab_generation` 补充来源、阈值及低分待复核标记。该分数评估的是演化前的问题，不代表最终答案正确性。生成结果仍应人工审阅。

文档当前沿用 PrismLab 的文本解析与约 4000 字符切分，Dify 使用现有分段；按顺序组合相邻片段，均匀选取来源生成。**尚未接入** SDK `generate_goldens_from_docs` 的 embedding 语义组块、文档质量选择，也未接入 `ConversationalGolden` 多轮对话。大知识库不保证每个片段都有对应问题。

## 标准 Golden 格式

以 SDK 的 `Golden` 模型作为字段和类型的唯一依据。JSON 导出是 `Golden.model_dump(mode="json")` 的记录数组，JSONL 每行一条，CSV 为同名列。支持 SDK 的 snake_case 字段及其 camelCase 序列化别名，保留完整单轮 Golden 字段：

```json
[
  {
    "input": "PrismLab 是什么？",
    "expected_output": "PrismLab 是 AI 模型测试与分析平台。",
    "context": ["PrismLab 是 AI 模型测试与分析平台。"],
    "additional_metadata": {"source": "product.md"},
    "source_file": "product.md",
    "expected_tools": [{"name": "search", "input_parameters": {"q": "PrismLab"}}],
    "expected_labels": {"intent": "product"},
    "expectations": {"must": ["回答基于资料"], "must_not": ["编造信息"]}
  }
]
```

`input` 为非空字符串，`expected_output` 为可空字符串。`context` 为参考上下文；`retrieval_context` 与 `actual_output` 用于记录实际系统结果，不能混作标准答案。还支持工具调用、comments、name、custom_column_key_values、token_cost 和 token 数等 SDK 字段。字段类型由 SDK 校验；未知字段和冲突别名会拒绝导入，避免静默丢失内容。

直接在 Python 中加载导出的 JSON：

```python
import json
from deepeval.dataset import EvaluationDataset, Golden

with open("dataset.json", encoding="utf-8") as f:
    dataset = EvaluationDataset(goldens=[Golden(**row) for row in json.load(f)])
```

JSON 导入也支持含 `goldens` / `items` / `data` 数组的对象。CSV 的 context / retrieval_context 沿用 SDK 的 `|` 分隔格式，也接受 JSON 数组；其他列表、对象使用 JSON 编码，并按 CSV 规则转义双引号。问题、答案是普通文本。CSV 无法区分空字符串与 null，且上下文中的 `|` 存在歧义，需要完整无损传输时请使用 JSON / JSONL。支持 UTF-8 和 GB18030 编码。

应用的 ID、时间戳和启用/归档状态属于管理信息，不进入 Golden 导出。点击「批量导出」在弹窗中选择范围与 JSON / JSONL / CSV 格式；有勾选时默认导出已选记录（包含跨页勾选），也可切换为导出整个数据集。无勾选时默认导出全部数据，不受搜索条件影响。导出包含所选范围内的启用和归档数据项，归档状态不随标准格式传输；追加导入创建新本地 ID。所选记录失效时拒绝导出并提示刷新，避免意外扩大范围。导入的多模态映射不允许引用服务器本地文件；当前功能面向文本 RAG 数据。

## 旧数据兼容

旧 `reference_contexts` / `contexts` 转换为 `context`，`metadata` 转换为 `additional_metadata`，接受 `question` / `answer`、`user_input` / `reference`、`ground_truth` 别名。旧的对象或数组型问题、答案转换为 JSON 字符串；原始类型和值保存在 `additional_metadata._prismlab_legacy_values`，若该键已存在则使用额外下划线避免覆盖。

历史数据库 payload 在读取时兼容转换，原始记录保留；新增和编辑使用标准 Golden 字段。转换是幂等的，不重写历史资料或删除字段。旧内置提示词自动采用新的 SDK 任务提示词，自定义提示词保留。

## 样本生成追溯

每条样本提供「生成提示词」和「上下文与来源」只读入口。新生成的样本关联独立保存的任务提示词、质量评审提示词、模型信息、生成时的来源片段，以及逐次发送给模型的完整消息和推理参数（包含 SDK 补充的 JSON Schema）。不记录认证请求头、API Key 或服务地址。请求列表分页加载，展开单个请求才读取完整消息。

DeepEval 和官方 RAGAS 可能在一个批次中批量生成、评审和改写多条样本，因此完整请求记录明确标为「同批次模型请求」；每条样本另有独立的原始问题、答案和参考上下文快照。后续修改配置、同步知识库或编辑样本不覆盖生成快照，编辑后的样本会显示差异提示。取消后的旧任务不能追加追溯记录或继续发送新请求。

历史、手工创建或导入的样本如无请求记录，会明确提示无法还原当时的提示词，仅显示已保存的上下文，不使用当前配置推测历史输入。追溯记录按空间与数据集隔离，删除数据集时一并删除。追溯关联属于本地管理信息，不进入标准 Golden 导出；重新导入不会自动关联旧请求。

## 进度、恢复与用量

数据集构建的生成、改写和质量评审请求需要结构化答案。对于 `config/llm-models.yaml` 已明确声明支持关闭思考的模型，这些请求使用非思考模式，避免模型将整个请求时间用于推理。未知模型不发送思考参数；此策略不改变 Playground 或评测目标的推理设置。实际发送的参数包含在同批次模型请求追溯中。

后台按批次执行并保存结果。正在生成的数据集列表和详情状态每 2 秒自动更新，显示真实的已完成 / 目标条数；详情还显示本次模型请求次数、进行中的请求数、当前请求等待秒数和连续失败重试次数。样本列表在任务结束或手动刷新时重新加载，编辑草稿不会随进度刷新重置。单次模型请求最多等待 180 秒（部分请求使用更短超时）；连续失败首次尝试后最多重试 2 次，认证、权限或额度等不可恢复的 HTTP 错误立即停止。没有有效新样本的连续批次同样受重试上限限制，成功生成后重置连续失败计数。输出会经过 Golden 校验和忽略大小写/空白的完全重复检测，未达到目标条数会标记失败并保留已有结果，支持继续构建。服务重启也会标记未完成构建失败。重试沿用参数和提示词快照，读取当前凭据；文档和种子使用保存的来源快照，Dify 成功拉取后也保存快照，避免续建混用不同版本的资料。

点击「取消生成」会停止后续模型请求和重试，旧任务晚到的结果不能写入数据或覆盖新任务状态。追加生成保留已保存样本；重新构建保留原有样本，丢弃尚未提交的替换结果。取消后可点击「继续构建」；重新构建会重新生成整批样本。

记录模型请求次数及上游返回的输出 token 数；自定义端点缺少统一定价，费用为未知，不显示为零。上游未返回的用量和失败请求消耗可能不包含在 token 统计中。SDK 遥测关闭，异步生成结果仅保存在本应用，不自动上传 Confident AI。

每次上传最多 20 个文档 / 10 MB，提取文本总量最多约 200 万字符；Dify 文本量同样受限。每次导入最多 10 MB，每个数据集最多 20000 条，每条最多 200000 字符。文件全部验证后再写入；构建过程中支持查看、搜索和导出，编辑和删除需等待完成。删除数据集会一并删除其源文本及种子快照。

个人与团队的数据集、来源、默认模型和提示词按 PostgreSQL schema 隔离。团队成员可维护数据集及使用团队模型，仅所有者和管理员可修改空间默认配置。

## API

沿用登录、CSRF 和 `X-Workspace-Id` 空间上下文。接口参数见应用 API 文档。

| 路径 | 用途 |
| --- | --- |
| `GET/POST /api/datasets` | 分页搜索 / 创建空数据集 |
| `POST /api/datasets/import` | multipart：`name`、`description`、`file` |
| `POST /api/datasets/generate` | multipart：`name`、`description`、`options`（JSON）、`files` |
| `GET/PUT/DELETE /api/datasets/{id}` | 状态 / 修改名称描述 / 删除 |
| `POST /api/datasets/{id}/retry` | 继续未完成的构建 |
| `PUT /api/datasets/{id}/generation-config` | 保存 `GenerationOptions` 及可空专用 `prompt` |
| `GET /api/datasets/{id}/sources` | 来源名称、片段数和同步时间；不返回原文 |
| `POST /api/datasets/{id}/documents` | multipart `files`，追加文档资料 |
| `POST /api/datasets/{id}/sync-dify` | multipart 重复的 `config_ids` 字段，追加或更新选中的知识库快照；兼容单个 `config_id` |
| `POST /api/datasets/{id}/build?mode=append` | 新增配置数量的问答；`mode=replace_generated` 成功后替换 AI 记录 |
| `GET/POST /api/datasets/{id}/items` | 分页搜索 / 添加 Golden |
| `PUT/DELETE /api/datasets/{id}/items/{item_id}` | 替换 Golden 与状态 / 删除 |
| `GET /api/datasets/{id}/items/{item_id}/generation` | 样本原始快照、生成提示词及来源快照；无记录时明确标注 |

| `GET /api/datasets/{id}/items/{item_id}/generation/requests/{request_id}` | 展开一条请求的完整消息与参数 |
| `POST /api/datasets/{id}/import` | 追加导入 |
| `GET /api/datasets/{id}/export?format=json` | `json` / `jsonl` / `csv` Golden 导出 |

| `GET/PUT /api/dataset-settings` | 生成模型 `default_llm`、质量评审模型 `default_critic_llm`、生成提示词 `prompt`、质量评审提示词 `critic_prompt`；提示词传 `null` 恢复各自默认值；省略 `critic_prompt` 保留原值 |

`options` 示例：

```json
{
  "method": "contexts",
  "size": 50,
  "llm": {"id": "provider-config-id", "model": "model-alias", "credential_id": "credential-id"},
  "quality_threshold": 0.5,
  "max_quality_retries": 3,
  "num_evolutions": 1,
  "evolutions": {"CONCRETIZING": 1, "CONSTRAINED": 1, "COMPARATIVE": 1},
  "max_concurrent": 3,
  "context_size": 2,
  "include_expected_output": true
}
```

省略 `llm` 使用空间默认模型。`critic_llm` 使用相同选择结构，省略或为 `null` 时继承空间质量评审模型；若空间未配置则复用生成模型。显式传入生成模型的选择结构可覆盖已配置的空间评审模型。实际选择保存为任务快照，失败重试沿用该快照。旧客户端保存空间设置时省略 `default_critic_llm` 会保留原值。从 Dify 生成时传 `dify_config_ids: ["config-a", "config-b"]`、省略 `files`；兼容旧的单个 `dify_config_id`。多个知识库的来源合计最多 200 万字符 / 10000 个片段，知识库配置与真实分段 ID 均保留。种子扩写传 `method: "goldens"` 和 `seed_dataset_id`；无资料生成传 `method: "scratch"` 及非空 `task`，后两者均不上传文件。

### RAGAS 问题类型与模拟提问者

官方生成模式按“问题类型占比”配置单跳、多跳抽象、多跳具体问题，三项合计 100%；拖动一项会按其余类型的比例重新分配。默认全部单跳，可点击“全部单跳”恢复。已有权重按比例显示为百分比，仅打开配置不改写原权重；调整后按新占比保存。实际生成条数可能存在取整偏差，多跳依赖可关联的资料。

“模拟提问者（可选）”影响问题的关注点和表达方式，可点击普通客户、客服专员、技术人员示例填入，格式为每行 `名称 | 角色描述`。留空时由 RAGAS 根据资料自动生成，与问题类型占比独立。

### 按用途设置参考答案默认值

新建数据集或首次配置生成参数时，“检索评测”默认关闭生成参考答案，“RAG 评测”和“两者通用”默认开启。创建时切换用途会应用对应默认值，用户仍可手动覆盖；已有明确保存的开关保持原选择，API 显式传入的值优先。未保存生成配置就直接构建时，后端也按当前用途取默认值。已有问答、冻结版本和失败任务参数不回写。

检索排序指标使用数据样本中已有的相关片段 ID 或分级相关性，ID 须与检索服务实际返回值一致。新建评测只有在所选指标需要参考答案时，才显示补充答案的指引，不自动生成或补写答案。

关闭参考答案后，DeepEval 使用 SDK 的问题生成选项，RAGAS 兼容路径请求空参考答案，官方 RAGAS 使用仅输出问题的提示词并保留官方场景生成及来源上下文流程，避免生成答案后再丢弃。

`POST /api/datasets/{identifier}/cancel` 取消当前空间的生成任务；重复取消同一已取消任务保持幂等，已完成任务返回 409。
